# Entity Modified

Backdrop does not force entity types to provide a last modified date, nor
provides any standard naming convention for those that do.

This module steps in to provide a programmatic way to retrieve the name of the
modified property. When the name is unknown, entity modified tracks the date
itself.

This module will not provide anything worthwhile on its own, so only install
this module if another module depends on it.

## Installation

- Install this module using the [official Backdrop CMS instructions](https://backdropcms.org/guide/modules)
